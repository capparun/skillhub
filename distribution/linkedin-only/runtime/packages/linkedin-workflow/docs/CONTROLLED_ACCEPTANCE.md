# 仓库化受控验收进展

已补23组受控测试；这是23组技术场景，不是26个顶层E2E用例全部通过。运行工具位于 test/acceptance/，通过 npm run test:controlled 显式执行。Playwright仅为开发验收依赖，生产CLI仍无Node第三方运行时依赖。

## 本次证据

- 独立Chrome实际DOM：正常2条结果、明确空结果/弹层（前轮证据）、100条声明总数但可用窗口仅2条时不得报平台全集。
- 第二页超时：第一页事实保留、正式CLI导出无损、同账号原查询恢复；重复ID合并，同名不同ID保留，重复实体的多页命中位置保留。另一个Profile零派发拒绝。
- 本地预算：18次预算用尽前保留第一页，Next点击未派发，关闭预算已预留；恢复不重复累计。
- 续页：改指纹、坏校验和、版本不兼容、过期、已存查询被改，均通过正式CLI零派发拒绝。
- 错误：403、限流、窗口不可见、超时、选择器失配、真实DOM分页结构缺失、查询变化、身份变化、可见弹层分别分类并有限停止。收集阶段可返回partial，不能误报空结果或完整成功。
- 额度：套餐及当前余额unknown时，已验证搜索独立可用；本地预算单列。公司搜索未就绪时，同一诊断允许人员搜索成功、拒绝公司搜索且不打开公司业务页。
- 后置验证：关键词已输入但页面查询未应用，以及关键词已应用但字段点击未应用，两种场景都返回search_not_confirmed，附requested、observed_keywords、observed_filters、验证阶段及页面。
- 候选及输入：两个相同显示名候选不猜选；八类非法条件/URL/limit/模式/业务参数无平台派发。
- 详情：公司缺失字段保留not_observed，错实体URL拒绝；人员展开About与当前任职partial语义正确。
- 同一Profile互斥：首任务已持锁时，第二CLI任务profile_busy且零平台派发；首任务随后正常关闭页面。

这些场景使用受控OpenCLI协议桥和合成账号门禁，不是实时LinkedIn错误布局。实际输入、点击、DOM提取和收集逻辑通过生产CLI执行；真实OpenCLI行为由L字段矩阵单独验证。历史各组开发源码证据单独保留。2026-10-20已对隔离安装的固定候选0.1.0-dev.8执行整轮23组，全部通过；508次受控协议调用，生产源码哈希逐项匹配候选清单。
