生产CLI和transport经受控OpenCLI协议桥调用独立无登录Chrome，实际执行关键词fill/Enter、生产DOM提取脚本和收集逻辑；所有网络请求拦截或中止。账号门禁使用去身份化协议夹具，不能把这些记录称作真实站点错误布局或完整OpenCLI内部实现验证。真实OpenCLI执行证据由L字段矩阵单独提供。

- 正常搜索：实际DOM有两条公司实体，精确总数2，读取两条并确认窗口末页；关闭owned会话。
