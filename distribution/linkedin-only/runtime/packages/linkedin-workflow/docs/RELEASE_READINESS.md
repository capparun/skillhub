## 用户现在可以怎样使用

在已连接且已核对身份、具备 Sales Navigator 权限的 Chrome Profile 下，由 Agent 准备搜索条件，再运行 `opencli hunter-linkedin salesnav-lead-search --input search.json`。结果必须同时看返回数量、总量、完整性和停止原因：返回3/177人表示仅取得部分结果；verified_empty 表示确认无匹配；执行失败不能解释为无人。

普通账号不能使用 Sales Navigator 搜索，必须按账号已验证能力选择普通 LinkedIn 路径。Premium 不等于 Sales Navigator；RPS 尚未实现。业务是否符合要求由模型判断，CLI 负责读页面、执行条件及返回证据。

完整参数和各入口证据见 [LinkedIn CLI 命令表](../workflow-runs/linkedin-integration/CLI_MATRIX.html)。当前范围排除发送与邀请的真实执行。
