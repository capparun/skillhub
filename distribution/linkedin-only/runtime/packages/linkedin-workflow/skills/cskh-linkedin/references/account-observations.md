# 每次任务需要区分的事实

资料基线核对日期：2026-10-25。知识说明不等于当前账号回执；不是自动检测功能已实现的声明。


| 层级 | 应记录的信息 | 不允许的推断 |
|---|---|---|
| 身份 | Chrome Profile、LinkedIn 精确身份、观察时间与来源 | Chrome 登录邮箱等于 LinkedIn 登录身份 |
| 套餐 | 产品、套餐原文、席位/试用状态（若可见） | Premium 徽章证明 SN 或 RPS 可用 |
| 操作权限 | 指定入口和动作；available / unavailable / unknown / blocked；原因及来源 | 页面可访问证明 API、发送或所有筛选可用 |
| 平台余额 | 产品、额度类型、余额原文、数值（可解析时）、续期时间（可见时） | 本地计数或月度赠送量等于当前平台余额 |
| 本地预算 | 本任务操作/页数/详情/时间预算与已用量 | 本地预算剩余等于平台允许量 |
| 插件支持 | 已实现、已接入、测试证据与未验范围 | 注册命令或帮助可见等于当前可执行 |

以上为知识与记录契约；不是声明当前 CLI 已能自动读取全部字段。缺少确定性读取能力时明确缺口，不能让模型猜页面内容。
