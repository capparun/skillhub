# 搜索与资料读取：选择方式

资料基线核对日期：2026-10-25。知识说明不等于当前账号回执；不是自动检测功能已实现的声明。

1. 根据本次需求只检查需要的功能；普通账号与 Premium 使用实际支持的普通入口，SalesNav 是可选增强。RPS 尚未开发。
2. 确认指定 Chrome Profile 内的 LinkedIn 身份；不能以 Chrome 邮箱代替账号身份。已知精确链接可直接读取，不强制先搜索。
3. 结合入口可见权限与插件实现选择操作。Premium 标签不证明 SN 可用，SN 页面可访问不证明 API 或全部筛选可用。
4. 没有 SN 订阅可选择普通路径，但必须说明缺少的高级筛选，不静默删条件。模型可基于后续资料判断，缺证据不能计为符合。
5. 分开记录结果总数、实际读取、游标与本地预算。不要硬编码每日搜索限额或把本地预算当作官方剩余量。
6. 验证、限流、未知派发时停止依赖动作，不自动换渠道绕过。适配器误报不等于平台真的限制，先保留原回执并定位。

同任务同账号复用仍有效的检查；账号切换、断线、订阅变化、上下文过期或权限拒绝后重检。复用只省去重复发现，不取消执行器现有身份校验。无有效期或时间来源的旧回执不能默认有效。余额等动态事实不能仅凭历史记录授权发送。

只有遇到套餐差异会影响本次决定、来源过时或冲突、用户要求最新权益时，才补充核对官方说明。不要每轮搜索都重新查询套餐介绍。字段记录不清时按需读 [账号观察字段](account-observations.md)，无需默认加载其他专题。
