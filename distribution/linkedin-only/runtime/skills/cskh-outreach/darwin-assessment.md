## 核验结果

| 核验项 | 结果 |
|---|---|
| 两层能力探测 | 会话入口与候选人动作分离；账号套餐不替代当前页面证据 |
| 只读边界 | 顶层与快照同时固定 `advisoryOnly=true`、`executionAllowed=false` |
| 候选人绑定 | 仅接受 HTTPS、`linkedin.com` / `www.linkedin.com` 与精确 `/in/<slug>` |
| 页面作用域 | 顶卡按 `expectedName` 定位；找不到时不回退整个页面 |
| More 菜单 | 仅观察当前按钮控制或点击后新出现的菜单；无法确认时返回 warning |
| 执行前复核 | 要求已认证、5 分钟内探测、路由仍可见；Pending 阻断重复 Connect |
| 审批时效 | 执行审批与 Connect 准备确认有效期 15 分钟；未来时间只允许 60 秒时钟偏差 |
| 未观察到能力 | 保留 `not_observed`，不解释为平台永久不可用，执行路径 fail closed |
| 自动测试 | Hunter 84/84；所有工作区插件测试通过；Skill 校验通过 |
| 真机只读 | Shawn Ruan 一度关系：Message 位于主页，Connect/Pending/InMail 未观察到；未发送 |

## 保留边界

1. 不同账号、关系和页面形态仍需逐步扩展真机场景矩阵。
2. 当前 Shawn Ruan 页面未可靠观察到 More 菜单内容；系统按 `not_observed` 停止 Connect，而不是猜测。
3. 页面结构变化仍可能导致探测失败，但不会降级为未经验证的发送路径。

结论：`1.6.0` 没有扩大真实发送权限，在执行前增加了可见能力、登录态和时效检查，符合 Darwin 棘轮规则与奥卡姆剃刀，建议保留。
