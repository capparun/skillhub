# 猎策 Hunter Works 产品规格（MVP）

## 1. 产品定位

猎策是面向 SOHO 猎头的官方 Skill 分发站。它负责展示、安装、授权和更新 Hunter Skills，不承载真实猎头项目的执行过程。

用户在网站上理解能力并取得安装入口；JD、候选人、浏览器登录态和执行结果始终留在用户自己的 Agent 与本地环境中。

## 2. 首发用户与商品

- 免费入口：职位需求对齐 Skill，任何用户无需登录即可安装和更新。
- 付费用户：由管理员指定并开通专业版授权的用户。
- 首发付费商品：SOHO 猎头人才寻访工作流。
- 免费能力：JD 诊断、关键问题追问、人才画像、搜索方向与寻访任务书。
- 付费能力：猎聘寻访、LinkedIn 寻访、候选人匹配排序、候选人初评与寻访报告。
- 首发不包含：脉脉寻访、谷露 ATS 对接、第三方作者市场。

## 3. 用户体验

### 公开访问

访客可以查看全部能力说明、适用场景、演示和示例，并直接取得免费“职位需求对齐”Skill 的安装内容。专业版安装仍需登录和有效授权。

### 授权与安装

免费 Skill：

1. 用户选择“Agent 用户”或“命令行用户”。
2. 用户直接复制公开安装 Prompt 或命令，不要求登录。
3. Agent 检查环境并说明将发生的变更，取得用户确认后安装和诊断。

专业版：

1. 用户使用邮箱和密码登录。
2. 服务端确认该用户拥有有效年度授权。
3. 用户选择安装入口；两者只是入口不同，不代表两类产品。
4. 服务端生成短时、一次性安装令牌。
5. 用户复制安装 Prompt 或命令，交给本地 Agent 执行。
6. Agent 检查环境并说明将发生的变更，取得用户确认后安装和诊断。

首发支持可访问本地终端与文件系统的 WorkBuddy、Codex、Claude Code 和 OpenClaw。OpenCLI 是 Hunter 的本地运行组件之一，不作为用户类型展示。

### 使用与更新

- Skill 的日常使用不请求 SkillHub，不上传业务数据。
- 本地最多每 24 小时静默检查一次公开版本元数据；网络失败不打扰用户。
- 有新版本时由 Agent 提醒，用户确认后再更新。
- 免费 Skill 使用公开版本和包哈希进行更新，不需要授权凭据。
- 专业版更新使用首次安装时签发的可撤销更新凭据，并校验授权状态、包哈希和版本。
- 授权到期后，已安装版本仍可使用，但不能取得后续更新。
- 首发不限制设备数量。

## 4. 云端边界

云端保存：

- 登录账号与密码哈希；
- 商品、版本和发布包元数据；
- 用户授权状态与到期时间；
- 一次性安装令牌和更新凭据的哈希；
- 必要的管理员审计记录。

云端不保存：

- JD、客户需求和人才画像；
- 候选人资料、搜索结果和评估报告；
- 浏览器 Cookie、账号密码和登录态；
- Agent 对话、Prompt 内容和 Skill 执行结果。

## 5. 管理后台

MVP 仅提供最小管理能力：

- 创建、停用用户和重置密码；
- 开通、撤销或调整授权到期时间；
- 查看一次性令牌是否已兑换；
- 查看当前正式发布版本；
- 查看关键管理员操作记录。

不提供用户仪表盘、设备管理、在线 Skill 编辑器和复杂运营系统。

## 6. 验收标准

- 未登录访客可直接安装免费的职位需求对齐 Skill，但无法取得专业版安装令牌。
- 有效授权用户可取得一次性、短时有效且只能兑换一次的安装令牌。
- 安装包来自私有发布源，并在安装前后完成完整性校验和诊断。
- 用户可以分别复制 Agent 安装 Prompt 和命令行安装命令。
- Skill 在断网状态下仍可正常执行核心猎头工作流。
- 授权到期不破坏已安装版本，但更新接口会拒绝下载新版本。
- 管理员可完成用户和授权的最小闭环操作。
