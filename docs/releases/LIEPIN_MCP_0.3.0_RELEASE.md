# 猎聘 MCP 0.3.0

从历史OpenCLI插件入口迁移到固定opencli-mcp Site Adapter与HL MCP兼容扩展。包含搜索筛选、列表前后翻页、可见详情读取、收藏及分组核验、任务恢复与报告。保留现有浏览器权限，不自动联系、不付费解锁。详情访问人数在任务开始前单独确认，其他操作保留审计。

Windows下载入口改用Node默认HTTPS证书校验，兼容PowerShell5.1中文编码和原生命令日志；不关闭证书检查。Windows候选完整安装、doctor和既有浏览器合成操作通过；Mac隔离安装与doctor通过。真实招聘业务不因安装通过自动视为已验收。

HL MCP扩展显示版本0.3.0-alpha.1，上游扩展版本0.0.22，与产品包0.3.0分别记录。首次安装仍需加载扩展、注册本机通信并配置所选MCP助手；不自动修改其他MCP。
