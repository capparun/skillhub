# 产品二级导航调整（本地预览）

日期：2026-10-15。范围：LinkedIn、猎聘、Gllue 三个独立页面。预览记录生成时尚未提交或部署；后续发布见上线申请与执行回执。

## 修改
- 共用 ProductSectionNav，统一产品介绍、安装与连接、使用示例入口；Gllue 保留命令参考。
- Logo、导航与正文对齐；移除普通链接下划线和多余分隔线。
- 点击及 URL hash 对应项显示加粗与短下划线；不实现滚动位置自动跟踪。
- 手机端允许换行，点击高度至少 44px；Gllue 增加两行吸顶导航的锚点留白。
- 猎聘使用示例导航及入口按现有版本条件展示，避免不可用锚点。

## 验证
- TypeScript、相关文件 ESLint 与 Next.js build 通过；最后一处条件渲染调整后再次 TypeScript 通过。
- LinkedIn 桌面浏览器实测 Logo、导航、正文左边缘均150px、宽1040px；使用示例点击高亮通过。
- Gllue 320px 导航换行及命令参考跳转通过，无横向溢出。
- 猎聘本地版本不可用时不显示使用示例导航；本地预览未连接生产数据库，不代表线上版本异常。
- 本轮不修改 Skill 安装包、浏览器扩展或账号数据。
