Windows WorkBuddy 安装与首次搜索

下载本页的 1.7.2 ZIP，完整解压，在包含 install.mjs 的文件夹打开 PowerShell。准备 Node.js 20.18.1 或以上版本。

$project = Read-Host 'WorkBuddy 已打开项目的完整路径'
node .\install.mjs --agent workbuddy --project-dir "$project" --preflight --json
node .\install.mjs --agent workbuddy --project-dir "$project"
node .\doctor.mjs --agent workbuddy --project-dir "$project" --json

打开 Ego Lite 完成首次设置，重启 WorkBuddy，在同一项目中新开对话。请助手运行 Get-Command ego-browser 和 ego-browser nodejs -e "console.log('ready')"。看到 ready 后，说“使用猎策脉脉搜索产品经理，最多 5 人，只浏览并导出 HTML”。在 Ego Lite 中亲自登录。Windows 真实页面仍待验收。

安装、升级与首次登录

下载 1.7.2 ZIP 并解压，把解压目录交给目标项目中的 Codex。Mac 已实测。在线寻访需单独安装 Ego Lite、打开 App 完成初始化，并准备脉脉招聘账号。Windows 可处理本地结果，Linux 本版未实机复验。

检查 Node.js 20.18.1+ 和 ego-browser 0.5.1+。按安装包的安装说明，把 Skill 装到当前 Codex 项目，运行 doctor。

doctor 通过后重新打开项目对话。让助手运行 login，在 Ego Lite 窗口登录，再运行 login --resume 和 health。升级时在原项目目录运行新版安装器。

搜索、筛选与看履历

从关键词或已有资源开始，无需先准备 JD。搜索时说清楚地区是期望工作地还是现居地、最多看多少人。

搜索产品经理，期望城市上海，最多 3 人。先回报选中的标签，再读取这 3 人页面可见的经历。

保存任务编号（run）。打开单人详情用候选人 ID，缺 ID 时用该任务返回的唯一指纹。批量读取可从已保存游标继续。只有单独同意下载附件时才保存原文件。

比较、审核和交付短名单

比较可见经历，缺证据的条件标为待核实。审核页可展开资料，逐人选择入选、淘汰或暂缓并写理由。

把刚才任务做成审核页。等我导出全部决定后，帮我导回同一个任务，把入选名单导出 CSV。

点“保存全部决定”下载 JSON，再交给助手导入。关闭页面前先保存。普通 export 导出采集结果，review 按人工决定导出短名单。

已有职位、投递、访客和推荐

先列出现有职位，按职位 ID 查看待处理投递、访客或推荐。overview 显示当前首页统计。

列出在招职位。我选一个后，读两条待处理投递，预览其中一人的“通过初筛”，保留当前状态。

application-review 只预览通过初筛或不合适。推荐为空就报告空；当前账号已验证真实空列表，非空推荐详情尚待实测。

储备、会话和跟进草稿

从个人储备、企业储备、好友或历史对象中找人。读取已有会话可能标为已读。首次联系、回复和再次联系都可先准备本地草稿。

读取我指定的已有会话，引用对方原话，结合我提供的岗位信息拟回复。把草稿留给我确认。

草稿可确认、记备注并回查。消息不会自动发送。添加平台备注、特别关注、加入储备和关联职位会改变平台数据，先预览具体对象与内容，确认后提交一次并回读。

导出、变化与保存位置

CSV 用于表格整理，HTML 用于浏览审核，JSON 用于后续处理。默认任务目录是 ~/.maimai-scout/output，附件另存于 downloads。可用 MAIMAI_STATE_DIR 指定状态目录。

比较同一职位、同一筛选条件下的两次采集，列出新增、已变化和本轮没有看到的人。

两轮样本的差异只代表可见记录。保留同一状态目录、任务编号和原始文件，可继续审核、回读决定或导出。

遇到问题怎么办

找不到 ego-browser 时，先确认 Ego Lite 首次设置已完成，再让助手检查命令路径。找不到 Skill 时，核对安装的项目并重开对话。

告诉我失败在哪一步、页面实际显示什么，以及已有结果保存在哪里。先保留现场。

登录失效由本人重新登录。筛选不符先在原页核对标签。页面要求验证就停下，人工解除后只复验中断项。写入状态不确定时先查当前记录，避免重复提交；同一账号按顺序操作。

全部命令

独立运行时，入口为 node <Skill目录>/scripts/mm.mjs 命令 参数。任务编号、职位 ID、候选人 ID 和会话 ID 请从对应列表读取。

命令说明关键参数

export解析 list+detail → 保守去重 → 可选匹配 → CSV/JSON/HTML--run <id> [--format csv|json|html] [--incremental] [--persona '<json>'|--persona-file <path>]
