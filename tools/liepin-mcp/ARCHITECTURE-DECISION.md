# 猎聘交付架构：官方 Site Adapter 优先

用户于2026-10-20明确选择“优先用官方 site adapter”。最终入口为 **一个 opencli-mcp 服务 + 15个猎聘 Site Adapter + 本地任务工具 + 可复用 Skill**。`server.mjs` 是保留在开发源码中的历史原型，不随 Site Adapter 候选交付，不作为安装入口。

| 层 | 负责 | 边界 |
| --- | --- | --- |
| Skill | 需求与例外、关键词探索、平台条件映射、证据判断、授权内跟进与报告 | 不实现页面解析；客户JD和候选资料不是通用默认值 |
| Site Adapter | 搜索、列表、详情、方案、收藏及同组核验 | 仅固定猎聘页面；不提供任意脚本或任意URL业务接口 |
| 本地工具与业务库 | 任务、轮次、证据、去重、预算、队列、恢复和导出 | 本地分析不创建浏览器连接；历史操作与账户计数不重置 |
| 锁定运行时 | 官方opencli-mcp 0.0.30及单独校验的隔离补丁 | 增补同会话子标签能力，猎聘以外站点保持原合同 |
| 兼容扩展 | 连接与调试会话行为兼容 | 保留上游权限与许可证，不修改猎聘检测脚本，不声称不可探测 |

## 为什么需要兼容构建

上游AdapterContext的多标签接口不足以直接完成“点击卡片→唯一子页→核对身份→关闭自建页→返回原搜索页”。运行时与执行器补丁把受控的同会话生命周期传给猎聘Adapter，关闭权限来自当前调用确认的新建标签，而非历史ID或对所有标签的猜测。

连接兼容构建调整首次调试连接的Runtime自动事件订阅。业务不依赖控制台事件，并拒绝需要隐式订阅的路径；不能将取消订阅理解为所有站点或所有功能无影响。此补丁是本产品维护的兼容版本，不是官方发布的猎聘支持，也不是反检测保证。

固定依赖、扩展内容、运行时补丁、启动器和候选文件分别校验。公开稳定扩展ID服务于Native Messaging登记和升级复用，不是隐藏指纹。未扩大上游浏览器权限。

## 执行与恢复合同

- 一个任务绑定一个既有账户范围；任务请求与共享范围均记录预算及业务指纹。用户明确扩额只增加被批准的上限，保留历史与其他限制。
- 每次连续详情调用最多处理一份新详情，持久队列按正常让出继续。加载观察不重复执行可见阅读；未知结果暂停，不能当作普通让出重试。
- 稳定身份来自页面实际链接与详情ID；姓名、序号、旧CSS均不能跨结果集合充当身份。
- 取消、超时后清理当前调用持有的标签；清理失败和效果未知持久记录。进程重启不自动继承旧标签的关闭权限。
- 收藏保存与准确组归属是两种证据。写后新核验绑定同组已完成的写入回执，保留此前快照，不通过更换limit绕过去重。
- 普通回读错误不拆装扩展；必要宿主更新先备份再重连。同一兼容环境持续启用，官方原版可保留停用作为回退。

## 验收声明

真实搜索、连续详情、30个筛选参数分组回读、方案与收藏分别有版本化记录。新版阅读单样本约18.1秒，不宣称稳定平均耗时或全篇人工阅读。安装与源码独立重建有macOS证据；Windows真机及目标AI客户端首次业务仍未通过。完整状态在仓库的需求覆盖清单和交付检查维护，不能用历史测试数量替代当前完整验收。
